# Sicherheitsmeldungen

Dieses Repository ist eine GitHub-Skills-Lernübung mit einer fiktiven Schule.
Die Anwendung ist nicht für echte personenbezogene Daten oder einen
ungeprüften produktiven Einsatz vorgesehen.

## Schwachstelle melden

Bitte melde Sicherheitsprobleme über das
[private GitHub-Meldeformular](https://github.com/Razzeflo/octo_git-guide/security/advisories/new).
Veröffentliche ausnutzbare Details, Zugangsdaten oder personenbezogene Daten
nicht in öffentlichen Issues oder Pull Requests.

Beschreibe die betroffene Version beziehungsweise den Commit, die notwendigen
Schritte zur Reproduktion, die möglichen Auswirkungen und gegebenenfalls einen
Lösungsvorschlag. Verwende ausschließlich künstliche Beispieldaten.

Die weitere Abstimmung erfolgt im privaten GitHub-Bericht. Es besteht keine
zugesagte Reaktionsfrist. Wartung und Sicherheitskorrekturen beziehen sich auf
den aktuellen Stand des Standardzweigs; ältere Übungsstände werden nicht
gesondert unterstützt.
