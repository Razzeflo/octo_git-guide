# Verhaltenskodex für dieses Übungsprojekt

Dieses Repository ist eine GitHub-Skills-Übung mit einer fiktiven Schulwebsite.

## Zusammenarbeit

Beiträge und Diskussionen sollen respektvoll, sachlich und für unterschiedliche Erfahrungen offen sein. Konstruktive Kritik bezieht sich auf die Arbeit. Persönliche Angriffe, Belästigung, diskriminierende Inhalte und die Veröffentlichung privater Informationen ohne Zustimmung gehören nicht in das Projekt.

## Zuständigkeit

Die Repository-Verantwortlichen erklären die Regeln und bearbeiten Verstöße verhältnismäßig. Sie können unpassende Beiträge moderieren. Die Regeln gelten für Diskussionen und Beiträge im Projekt sowie bei dessen öffentlicher Vertretung.

## Meldungen

Verstöße ohne vertrauliche Angaben können den Repository-Verantwortlichen über GitHub gemeldet werden. Persönliche Daten nicht öffentlich posten. Sicherheitslücken gehören in den privaten Meldeweg gemäß SECURITY.md.

Diese Regeln orientieren sich am Contributor Covenant: https://www.contributor-covenant.org/version/1/4/code-of-conduct.html
